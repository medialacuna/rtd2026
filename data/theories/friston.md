# ФРИСТОН — принцип свободной энергии

Мозг — машина предсказания. Он минимизирует «свободную энергию» — меру расхождения между моделью мира и тем, что приходит от органов чувств. Не пассивный приёмник, а активный генератор гипотез: мир нам снится под надзором данных.

Для портала:
- Каждая реплика — предсказание автора о зале. Расхождение между репликами = error signal, по которому система учится.
- Конфликт полезен ровно так, как полезен prediction error: без него модельмира застывает.
- Ритуалы (такты, тосты) снижают свободную энергию круга: предсказуемая рамка, внутри которой можно удивляться.
- ИИ минимизирует собственную ошибку: каждый его вопрос — проверка гипотезы «между этими текстами есть узор».

Формула для ведущих: surprise — цена, learning — скидка. Зал платит вниманием; кто учится быстрее, тот диктует темп.
